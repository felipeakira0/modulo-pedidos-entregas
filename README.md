Módulo de Pedidos e Entregas

Objetivo do projeto

O objetivo deste projeto é organizar o desenvolvimento de um módulo de pedidos e entregas para um aplicativo de delivery.

O módulo deverá permitir o gerenciamento de pedidos, o cálculo de fretes, o processamento de pagamentos e o acompanhamento das entregas.

Este repositório apresenta a Estrutura Analítica do Projeto (EAP), organizando as principais entregas de forma hierárquica para facilitar o planejamento e o acompanhamento do desenvolvimento.
